## 2. Why Each Item Was Safe to Delete

Reference audit was run across `package.json`, `package-lock.json`, all `*.config.ts`, `*.tsconfig*.json`, `build.mjs`, `index.html`, `README.md`, `docs/*.md`, `src/**/*.{ts,tsx}`, `tests/**/*.{ts,tsx}`:

| Item | Evidence of no active reference |
| --- | --- |
| `Python/` | Not imported, not invoked, not globbed by any config/script/test. Only mentioned in the prior Phase 8 report and the old `.gitignore` entry — both documentation, not code. Its own `pythoncore`/`bin` are a self-contained runtime with no link to the app. Vite/Playwright/Vitest/Supabase CLI require no bundled Python. |
| `opendesign/` | No route, import, plugin, or asset reference in `src/`, configs, or tests. Served only by a separate static viewer workflow, unrelated to the Vite build. The sole app reference was a stale comment in `src/App.tsx` (now removed). |
| `.od-skills/` | Pure tool/skill snapshots; nothing in the app or build config reads them. |
| `.file-versions/` | Tool version-history metadata; nothing references it in source/config/tests. |
| `supabase/.temp/` | Generated by `supabase link`/CLI; regenerable. Migrations (`supabase/migrations/*.sql`) were NOT touched. |
| `dist/`, `test-results/`, `tsconfig.tsbuildinfo` | Regenerable build/test artifacts, all gitignored. |
| `node_modules/` | Regenerated by `npm install` (clean-install verification passed). |

Database migrations (`supabase/migrations/0001–0010`) remain untouched, verified present after cleanup (see §3).
